# P8セル 写真差し替えツール

橋梁点検エクセル（`.xlsx`）のP8セルに埋め込まれた写真を、指定フォルダ内の矢印記号付きJPGに自動差し替えするデスクトップツールです。

## 機能

- フォルダ内の複数エクセルを一括処理
- エクセルファイル名から橋梁名を自動抽出し、対応する写真フォルダを検索
- 全角・半角の表記ゆれを自動吸収（例：`津島１号溝橋` ↔ `津島1号溝橋`）
- ファイル名に矢印記号（`→` `↑` など）を含むJPGを自動選択
- 処理済みファイルは `_更新済.xlsx` として保存（元ファイルを上書きしない）
- フォルダ設定を自動保存（次回起動時に復元）

## 必要環境

- Python 3.10 以上
- 依存ライブラリ（下記インストール手順を参照）

## インストール

```bash
pip install -r requirements.txt
```

## 使い方

```bash
python p8_photo_replacer.py
```

または `起動.bat` をダブルクリック。

1. 「エクセルフォルダ」に対象の `.xlsx` が入ったフォルダを選択
2. 「写真フォルダ」に橋梁名フォルダが入ったルートフォルダを選択
3. 「▶ 一括処理を開始」をクリック

## 写真フォルダの構造

```
写真フォルダ/
  津島1号溝橋/
    現場写真→.jpg    ← 矢印記号入りが自動選択されます
    現場写真.jpg
  別橋梁名/
    ...
```

## 対応矢印記号

`→` `←` `↑` `↓` `↗` `↘` `↙` `↖` `⇒` `⇐` `⇑` `⇓`
