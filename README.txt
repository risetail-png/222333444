# P8セル 写真差し替えツール

## 使い方

1. `起動.bat` をダブルクリックしてアプリを起動
2. 「エクセルフォルダ」に対象の .xlsx が入ったフォルダを選択
3. 「写真フォルダ」に橋梁名フォルダが入ったルートフォルダを選択
4. 「一括処理を開始」ボタンをクリック

## 写真フォルダの構造

```
写真フォルダ/
  津島1号溝橋/
    現場写真→.jpg    ← 矢印記号入りが自動選択されます
    現場写真.jpg
  別橋梁名/
    ...
```

## 対応矢印記号

→ ← ↑ ↓ ↗ ↘ ↙ ↖ ⇒ ⇐ ⇑ ⇓

## 注意

- Python 3.10以上が必要です（https://www.python.org/）
- 初回起動時に openpyxl が自動インストールされます
- 処理済みファイルは元ファイルと同じフォルダに「_更新済.xlsx」として保存されます
- フォルダ設定は自動的に保存されます（次回起動時に復元）
